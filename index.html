今日作れるパン

もちっと噛みごたえのあるベーグル、クッキー生地をのせた甘いメロンパン、みんなで分けやすいふわふわのちぎりパン。 それぞれ家庭のオーブンで作りやすい分量にしています。

ベーグル

ゆでてから焼くことで、表面はつやっと中はもっちり仕上がります。

大さじ1

ベーグルの作り方

  1. こねる

    材料を混ぜ、表面がなめらかになるまで10分ほどこねます。

  2. 発酵する

    丸めて40分ほど一次発酵し、4〜5等分にします。

  3. 成形する

    棒状にのばして端をつなぎ、リング形にして15分休ませます。

  4. ゆでて焼く

    はちみつを入れた湯で片面30秒ずつゆで、200℃で15〜18分焼きます。

メロンパン

ふんわりパン生地に、サクサクのクッキー生地をかぶせます。

パン生地
強力粉200g、砂糖20g、塩3g、イースト3g、牛乳130ml、バター20g
クッキー生地
薄力粉120g、砂糖45g、卵1/2個、バター45g
仕上げ
グラニュー糖 適量
  1. パン生地を作る

    材料をこね、バターを加えてなめらかにし、40〜50分発酵します。

  2. クッキー生地を作る

    バター、砂糖、卵、薄力粉を順に混ぜ、冷蔵庫で休ませます。

  3. 包む

    パン生地を6等分し、薄くのばしたクッキー生地をかぶせます。

  4. 焼く

    表面に格子模様をつけ、グラニュー糖をまぶして180℃で14〜16分焼きます。

ちぎりパン

型に並べて焼く、やわらかくて分けやすい食卓向きのパンです。

強力粉
250g
砂糖
25g
塩
4g
ドライイースト
3g
牛乳
170ml
バター
25g
  1. こねる

    材料を混ぜてこね、最後にバターを加えてつやが出るまでまとめます。

  2. 一次発酵

    あたたかい場所で40〜60分、生地が約2倍になるまで発酵します。

  3. 並べる

    9〜12等分して丸め、型に少し間隔をあけて並べます。

  4. 焼く

    20分ほど二次発酵し、170℃で18〜22分焼きます。

おいしく作る共通のコツ

  • 粉気が残るときは、水分を一度に足さず小さじ1ずつ調整する。
  • 発酵時間は室温で変わるため、時間より生地の大きさと弾力を見る。
  • 焼き色が早くつく場合は、途中でアルミホイルを軽くかぶせる。

ひとこと

焼きたての香りは、おうち時間を小さなベーカリーに変えてくれます。好きなパンから気軽に試してみてください。
